# Python Calculator

A command-line calculator built with Python as part of my journey into programming and Python development.

The calculator supports basic arithmetic operations as well as additional mathematical operations such as powers, square roots, modulus, and floor division.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Power/exponentiation
- Square root
- Modulus
- Floor division
- Continuous calculator menu
- Input validation
- Division-by-zero protection
- Modulus-by-zero protection
- Negative square-root protection

## Technologies

- Python 3
- Python built-in functions and operators
- No external libraries required
